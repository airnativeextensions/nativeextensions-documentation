start()method 
public function start(config:PreloadConfiguration):Boolean

Starts preloading ads for the given adUnitId and PreloadConfiguration. The SDK continues preloading ads until the number of ads specified by getBufferSize is reached, attempting to keep the buffer full throughout the session. If a PreloadConfiguration was already started with adUnitId, this method becomes a no-op and returns false.

Parameters

config:PreloadConfiguration — The PreloadConfiguration to use for preloading ads.

Returns
Boolean — true if preloading started successfully, false if a configuration was already started for the given adUnitId.
