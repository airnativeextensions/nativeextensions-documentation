setBufferSize()method 
public function setBufferSize(bufferSize:int):PreloadConfiguration

Sets the buffer size for preloading ads. This determines how many ads will be preloaded and ready for display. The buffer size is capped at 15. Defaults to a Google-optimised buffer size if a non-positive number is set. Buffer size controls the number of preloaded ads held in memory. By default, Google optimises buffer size to balance memory consumption and ad serving latency. If your app displays ads before the next ad is loaded, you can set a custom buffer size to increase the number of ads kept in memory. Preload cache limits Google Mobile Ads SDK (Legacy) enforces an app-wide limit on the total number of preloaded ads across all ad units and preload IDs:

  • Default limit: Google Mobile Ads SDK (Legacy) holds a maximum of 6 preloaded ads in memory. This limit is shared across all formats and preload IDs.
  • We recommend to keep a buffer size of 2 or 3 per preload ID.

Parameters

bufferSize:int — The number of ads to preload and keep in memory. Must be a positive integer. The maximum allowed value is 15.

Returns
