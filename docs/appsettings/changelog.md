### 2026.10.08 [v1.0.0]

```
Initial release of the AppSettings extension which includes the User Defaults / Settings and Keychain functionality from the deprecated Application extension.

This initial release brings this functionality up-to-date using the modern approaches for Android Preferences and iOS User Defaults. It also includes support for tvOS and macOS.

### Updates

- feat(android): implementation of defaults, and settings
- feat(ios): implementation of defaults, keychain and settings
- feat(tvos): implementation of defaults, keychain and settings
- feat(macos): implementation of defaults, keychain and settings
- feat(default): fallback to AIR shared object on unsupported platforms
```
