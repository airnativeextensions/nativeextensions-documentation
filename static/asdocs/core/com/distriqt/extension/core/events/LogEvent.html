Packagecom.distriqt.extension.core.events
Classpublic class LogEvent
InheritanceLogEvent flash.events.Event

Dispatched by Core.service.logger when a native extension emits a log message through the extension:log status event.

Applications can listen for this event and route messages to a custom logging library:

     Core.service.logger.addEventListener( LogEvent.LOG, onLog );
          private function onLog( event:LogEvent ):void
     {
         customLogger.write( event.id, event.tag, event.message, event.level );
     }

Messages originating from ActionScript are filtered by the native Core implementation and are not redispatched as log events. Events are emitted only when the message passes the configured native log level. Delivery may originate from a native background thread.
